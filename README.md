# 技能五子棋

五子连珠的老规矩，加上封印、迷雾、震荡、策反等技能，以及棋盘四角的能量泉。

**在线试玩：** https://liukaidipeng-ops.github.io/gomoku/

## 怎么和朋友联机

1. 打开网址，点“在线对战”，再点“创建房间”。
2. 点“复制邀请链接”发给朋友，或者直接告诉对方 4 位房间号。
3. 朋友打开链接就会自动进入房间，不需要注册任何账号。

两部手机是直接连接的，房主的页面要一直开着。少数网络（比如部分公司 Wi-Fi）不支持直连，连不上时可以换成手机流量再试。

## 规则

完整规则见 [RULES.md](RULES.md)。游戏里点“规则”也能看到简版。

## 文件说明

- `index.html`：整个游戏，规则引擎、电脑对手、界面和联机都在这一个文件里。
- `peerjs.min.js`：联机用的 [PeerJS](https://peerjs.com/) 1.5.4（MIT 许可，见 `peerjs.LICENSE`）。

## 已知限制

- 迷雾棋子只在界面上隐藏，懂技术的人能从网页数据里看到。
- 电脑对手只会用封印和震荡，水平一般。
